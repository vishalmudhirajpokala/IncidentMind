What if the next incident started with evidence from the last one?
Can it show what changed?

IncidentMind makes the investigation inspectable:
• Query service, signals, release, and failure pattern.
• Separate memory-off, empty, and unavailable states.
• Show prior cause, action, outcome, and match rationale.
• Keep actions simulated and approval-gated.

In the verified local run, differently worded checkout symptoms recalled a prior incident. Memory-off suggested a generic rollback; memory-on named the known-good version. This is local-provider evidence, not a benchmark or live-Hindsight claim.

I chose Hindsight for the external memory boundary and kept provider status explicit.
